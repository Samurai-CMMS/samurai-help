# Create a Work Order

### Desktop

To create a Work Order in the Deskltop App, follow these steps.

1. From the side menu, select Work Management - Work Orders
1. Select + Add Work Order
1. Add a Title for the work order that briefly describes the work
1. Add an option description of the work
1. Select an Asset or Area. (An Asset or Area must be selected to open a Work Order)
1. Save the new Work Order

! The work order will save and then reopen providing more options.

Once saved, a work order is automatically assigned a Work Order Number.
