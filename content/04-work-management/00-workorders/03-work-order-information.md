# Work Order Information

The minimum information needed to create a work order is a title and selection of an Asset or Area, more information can be added to the work order.

This section describes the other information that can be collected on a Work Order.

#### Compliance Task

Flagging a Work Order as a Compliance Task, communicates that there is a legal requirement to complete this task. The Compliance Task flag is used in reporting to ensure assets have legally required work completed in a timely manner.

#### Work Order Status

The Work Order status is used to track Work Orders as they progress.

| Status | Description | 
|:---|:---|
| Open | The Work Order has been raised. | 
| In Progress | The Work Order is currently being executed. | 
| Complete | All work on the Work Order has been completed. | 
| On Hold | The work on the Work Order has been paused. | 
| Cancelled | The work order will not be completed. |

When raising a Work Order on the desktop for new work, it will typically be raised ion the default Open status. The mobile App is where technicians can pick upn the open Work Orders, execute the work and update the status to In Progress and Complete as the work progresses.
